# Scripture for Life

A quiet place to find help in God's Word. Scripture for Life is a static website for finding Bible passages for what you're facing (fear, grief, loneliness and more), exploring the people and stories of Scripture, and taking an interactive journey through Psalm 23.

It is plain HTML, CSS and JavaScript with no build step. Bible text is the public-domain Berean Standard Bible (BSB), stored per book in `bible/*.json`.

## View it

- Live site: https://dvdjoe-sudo.github.io/scripture-for-life/
- Locally: open `index.html`, or run `python3 -m http.server` in this folder and visit http://localhost:8000 (a local server is needed for the Bible reader to load its JSON files).
