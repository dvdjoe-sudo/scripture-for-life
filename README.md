# Scripture for Life — original-style review v4

This branch restores the approved original ivory, forest-green and sage visual identity and adds the Genesis 1–3 storytelling enhancements, 20 scenes, Psalm 23 pastoral study, 66-book journey, help topics, character profiles, narration, reader settings, notes and bookmarks. All 31,102 verses of the public-domain Berean Standard Bible remain in `data/bible.json` on the base repository.

Run: `python3 -m http.server 8000`, open localhost:8000. Android is an **unreleased starter**: Capacitor/Android Studio needed; change the placeholder app ID and test on devices before Play submission. This is a review branch, not automatically deployed to the hosted site.

See `ORIGINAL-DESIGN-DECISIONS.md` for style and art provenance. All Bible narrative retellings, illustrations and interpretation are labeled separately from Scripture.
