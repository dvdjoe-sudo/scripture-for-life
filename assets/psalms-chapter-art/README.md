# Psalms 37–150 chapter watercolors

One symbolic watercolor per psalm, shown at the top of every verse study in that psalm (Psalm 46 keeps its own art; Psalm 36 has per-verse art). Pilot batch: Psalms 37–45. Made with the built-in image generation tool to the standard in `../psalms/STYLE.md`; 1280 × 853 WebP, quality 82. Scene plan for all psalms is kept with the project notes. Figures are imagined, not identified biblical characters; no portrait of God.
