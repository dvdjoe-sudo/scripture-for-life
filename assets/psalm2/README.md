# Psalm 2 artwork

Twelve original symbolic watercolors, one per verse, created with the built-in image generation tool using the approved Psalm 23:2 painting as a style reference. The production files are `verse-1-watercolor.webp` through `verse-12-watercolor.webp`, resized to 1280 × 853 and encoded as WebP quality 82.

The paintings visualize changing poetic viewpoints, royal objects, serious warning, teachability, and refuge. They are not portraits of God, named rulers, historical reconstructions, or maps onto modern nations. Individual notes explain where an artistic detail is not named by the verse. Exact prompts are in `../psalms/generation-prompts-2-3.json`.
