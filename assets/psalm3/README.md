# Psalm 3 artwork

Eight original symbolic watercolors, one per verse, created with the built-in image generation tool using the approved Psalm 23:2 painting as a style reference. The production files are `verse-1-watercolor.webp` through `verse-8-watercolor.webp`, resized to 1280 × 853 and encoded as WebP quality 82.

The traveler is imagined, not a portrait of David or Absalom. Shield, prayer, sleep, courage, and shared blessing illustrate the prayer's themes. Verse 7 uses damaged equipment as a nonliteral response to a plea to end hostile power; the note expressly distinguishes this from the verse's jaw and teeth language. Exact prompts are in `../psalms/generation-prompts-2-3.json`.
