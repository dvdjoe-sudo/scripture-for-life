# Psalm 10 verse watercolors

Eighteen separately generated symbolic paintings, made with the built-in image generation tool using the approved Psalm 23:2 visual reference. Full shared and individual prompts are recorded in `generation-prompts.json`. Each production WebP is 1280 × 853, quality 82. All are bundled for the website offline cache and Android web assets.

Anonymous people and places are imagined, not biblical portraits or historical reconstructions. No figure represents God. Difficult themes are represented without graphic injury. Paintings were visually reviewed against each verse before integration.
