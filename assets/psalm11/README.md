# Psalm 11 verse watercolors

Individual symbolic paintings created with the built-in image generation tool using the approved Psalm 23:2 style reference. Full prompts are recorded in `generation-prompts.json`. Production files are 1280 × 853 WebP at quality 82 and included in the website offline cache and Android web bundle.

Anonymous human figures and imagined places are symbolic, not reconstructions. No figure or bodily form represents God; severe judgment imagery avoids graphic harm.
