# Psalm 6 verse paintings

Ten individual symbolic watercolors generated with built-in image_gen, using the approved Psalm 23:2 painting as the style reference. These are imagined devotional illustrations, not historical reconstructions. Prompts are retained in `../psalms/generation-prompts-6.json`. Production copies are 1280 × 853 WebP and included in website offline assets and the Android web bundle.
